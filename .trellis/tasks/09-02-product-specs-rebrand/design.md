# 技术设计：产品详情厂家资料脱敏重制

## 架构总览

纯静态硬编码替换，无数据流变更。

```
智慧养老厂家资料/*.pdf/.docx (本地只读)
  ↓ 人工提取 + 脱敏
src/page_product.html (3 分支硬编码)
  ├─ 产品介绍 4 卡片文案
  └─ 规格参数 8 行表格
.gitignore (忽略资料目录)
```

## 数据契约

### 提取-脱敏规则

- 保留：数值、单位、功能描述
- 去除：品牌（希卡立/驰通达）、型号前缀（X1/X2/L4P/SOS-C06）、Logo、联系方式
- 改写：如“希卡立 X1 60GHz 毫米波睡眠监测仪” → “60GHz 毫米波雷达，无感非接触”

### 模板映射

- `slug == 'vital-monitor'` 分支：对应 X1/X2 合并参数（取交集，差异处取较优值并注明“依型号”）
- `slug == 'fall-monitor'`：对应 L4P 参数
- `slug == 'emergency-button'`：对应 SOS-C06 参数

## 兼容与回滚

- 单文件 `page_product.html` 改动，`git revert` 即可回退为旧参数
- `.gitignore` 追加一行，无风险

## 风险

- 厂商标称为口误残留 → 验收时全库 grep 确保零命中
