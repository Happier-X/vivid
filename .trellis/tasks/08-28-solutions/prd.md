# 解决方案模块

## Goal

在现有顶部导航（首页、合作咨询、关于我们）基础上新增“解决方案”一级入口，并提供对应的单页模板，复刻 mikapu.cn 的版式质感，内容完整保留万椿智慧养老的 3+X 设备+平台+服务 与 4+N 健康监测-安全预警-生活辅助-社交陪伴体系及居家·社区·机构三场景。

## Requirements

- 顶部导航新增“解决方案”：桌面端与移动端均可见，顺序为 首页、解决方案、合作咨询、关于我们；与现有 `menuFinder.getPrimary()` 共存，未在后台配置时提供兜底展示
- 新建单页模板 `page_solutions.html`，在 `theme.yaml customTemplates.page` 注册为“解决方案”
- 页面首屏复用关于我们同款 `-mt-[76px] pt-[76px]` 透明头融合与 `#eef7f7` 浅青底，标题与简介居中
- 版式 1:1 复刻 mikapu：淡青方块图标 + 英文小标签 + 26px 标题，卡片圆角 12-16px，白底悬浮
- 内容保留万椿：三场景（居家/社区/机构）与 4+N 体系，数据与文案不使用 mikapu 占位
- 页脚与 CTA 的“解决方案”入口指向 `/solutions`
- 提供后台配置说明：页面别名需设为 `solutions`

## Acceptance Criteria

- [ ] 顶部导航可见 4 项且移动端同步
- [ ] 访问 `/solutions` 能渲染新模板，无 404
- [ ] 模板在 `theme.yaml` 中注册并可在后台单页模板下拉中选择
- [ ] 版式与现有关于我们/合作咨询保持一致的 mikapu 质感
- [ ] `pnpm build && pnpm check` 通过
