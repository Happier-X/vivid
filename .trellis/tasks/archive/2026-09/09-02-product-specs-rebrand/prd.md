# 产品详情厂家资料脱敏重制

## 目标

基于 `智慧养老厂家资料` 中希卡立 X1/X2（体征）、L4P（跌倒）、驰通达 SOS-C06（紧急按钮）的官方参数，脱敏重制为万椿品牌的产品介绍与规格表，更新 `page_product.html` 硬编码详情，全程不出现任何厂家名称/Logo/型号前缀。

## 背景与已确认事实

- 技术栈：`page_product.html` 硬编码单页模板，3 款产品 `vital-monitor / fall-monitor / emergency-button` 各含首图/产品介绍/规格表/CTA
- 已有资产：`智慧养老厂家资料/上海交大希卡立养老产品/产品说明书/*` 与 `驰通达养老产品/产品说明书/*`，含 PDF/DOCX 参数表与高清图（X1/X2/L4P/SOS-C06）
- 已决策：厂家信息不出现于前台，统一以万椿口径呈现；该资料目录已加入 `.gitignore`，不提交入库

## 需求

### R1 资料解析

- 提取 3 款核心参数：
  - X1/X2：监测方式/距离/监测项/联网/供电/安装/尺寸/工作温湿度
  - L4P：监测方式/范围/告警时延/联网/供电/安装/防护/准确率
  - SOS-C06：触发方式/通信/供电/防护/安装/告警通道/尺寸/续航

### R2 脱敏重制

- 将参数中的厂家品牌、型号前缀（如“希卡立 X1”）去除，改写为万椿中性描述（如“60GHz 毫米波雷达，无感非接触”）
- 产品介绍 4 卡片文案同步重制为万椿口径，不含厂家

### R3 模板更新

- `src/page_product.html` 中 3 个分支的“产品介绍”与“规格参数”表格按新参数硬编码替换
- 保持 `src/css/main.css` 现有 `product-specs` 柔和样式，无需新增样式

## 非目标

- 替换实拍图（本任务仅文案与参数，图片保持 `product-vital.png / product-diedao.png / product-sos.jpg`）
- 引入新厂家或新增产品
